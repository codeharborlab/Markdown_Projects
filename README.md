# Markdown Practice

This repository contains my **Markdown practice files and exercises**.  
The purpose of this project is to learn how to write and format documents using Markdown syntax, which is widely used on platforms like **GitHub, documentation sites, and developer tools**.

## 📚 Topics Covered

The files in this repository demonstrate different Markdown features such as:

- Headings
- Text formatting (bold, italic, strikethrough)
- Lists (ordered and unordered)
- Links
- Images
- Code blocks
- Tables
- Blockquotes

## 🎯 Purpose

- Practice writing Markdown syntax
- Learn how to structure documentation
- Understand how GitHub renders Markdown files
- Improve documentation skills

## 🛠 Tools Used

- Visual Studio Code
- Markdown (.md)
- Git & GitHub

## 📌 Notes

This project was created as part of **Markdown coursework and practice exercises**.
